# Logicmaker

## Overview

This project was originally developed as a web-based digital logic simulator inspired by software like Crocodile Physics, aimed at providing an interactive environment for working with logic circuits directly in the browser.

During the development process, [Logisim-Evolution](https://github.com/logisim-evolution/logisim-evolution) was identified as a powerful alternative that already featured many of the advanced capabilities intended for this web application. Because a mature and fully-featured tool meeting these requirements was found, the further active development of this web-based project has been concluded and the repository is now archived.

## Features

- **Browser-Based Interface:** Built as a web application for accessible circuit simulation.

- **Interactive Components:** Designed to support digital logic components, wires, and custom elements.
